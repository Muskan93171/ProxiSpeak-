# ProxiSpeak: Geospatial Proximity Audio Ecosystem
 
# About the Project:
ProxiSpeak is a location-based audio-sharing platform that enables users to discover, record, and listen to audio content associated with nearby geographical locations.

# Objectives:
Discover audio content based on geographical proximity.
Record and share location-linked voice messages.
Display nearby audio posts on an interactive map.
Support both website and mobile application platforms.

# Planned Technologies:
Frontend: HTML, CSS, JavaScript
Mobile App: React Native with Expo
Maps: Leaflet
Backend and Database: Supabase

# Key Features:
Interactive location map
Audio recording and playback
Nearby audio discovery
Location permissions and privacy controls
